# Scientific account and proof dependencies

The starting point is a **known** non-Gaussian free-particle diffusion model. The new question is whether it destroys *all possible* system–reference entanglement at finite time, and how the exact answer compares with the channel's distance to classical measure-and-prepare dynamics.

1. [Model and exact claims](model.md): Hilbert-space contract, unbounded normal stochastic channel, operational error and finite energy.
2. [Conditional Gaussian dynamics](conditional_gaussian.md): unravelling the quadratic shear, its physical displacement covariance, the Brownian Gram determinant and exact Laplace transform.
3. [Exact EB/PPT threshold](exact_threshold.md): pathwise Gaussian sufficiency followed by a separate unconditional finite-energy NPT converse using the Mehler kernel.
4. [Cubic operational proximity](cubic_distance.md): a uniformly valid diamond upper bound by replacing rare paths, and a *different* normalized compact-packet lower bound of matching logarithmic order.
5. [One fixed input](fixed_input.md): faithful-state filtering makes a single finite-energy two-mode squeezed vacuum an NPT detector for all finite times. This is qualitative.
6. [Interpretation and limits](interpretation.md): deterministic-shear Gaussian cutoff, singular weak-quadratic-noise limit, coding-fidelity consequence and what does not follow.

[Related work](../references/RELATED_WORK.md) distinguishes inherited model, Gaussian EB criterion and probability tools from the new operational conclusions. [Verification](../verification/README.md) documents finite parameter checks. The central analytical statements live in these topic pages rather than in a development diary or a separate manuscript file.
